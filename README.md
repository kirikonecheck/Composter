# Коллекция проектов Docker Compose

Этот репозиторий содержит подборку готовых конфигурационных файлов `docker-compose.yml` для быстрого развёртывания различных веб-приложений, баз данных и инструментов администрирования.

---

## 📌 Описание Docker Compose

**Docker Compose** — это инструмент, входящий в экосистему Docker, который позволяет описывать и запускать многоконтейнерные приложения. С его помощью вся инфраструктура проекта (сервер приложений, база данных, кэш, фронтенд) задаётся в одном текстовом файле формата YAML (обычно `docker-compose.yml`).

### Основные преимущества:
* **Однородная среда:** Гарантирует, что приложение будет работать одинаково на компьютере разработчика, стейджинге и продакшене.
* **Управление одной командой:** Запуск (`docker compose up -d`) и остановка (`docker compose down`) всей инфраструктуры одной строкой.
* **Изоляция сетей:** Контейнеры внутри одного проекта могут общаться друг с другом по именам сервисов, оставаясь защищёнными от внешней сети.

## 🚀 Список проектов в коллекции

### 1. Joomla
Популярная система управления контентом (CMS), используемая для создания веб-сайтов и мощных онлайн-приложений. 
* **Контейнеры:** Веб-сервер Joomla + база данных (обычно MySQL или MariaDB).

### 2. WordPress
Самая известная в мире CMS для блогов, новостных порталов и интернет-магазинов.
* **Контейнеры:** WordPress (на базе Apache/PHP) + СУБД MySQL.

### 3. MySQL + phpMyAdmin
Классический стек реляционной базы данных с удобным веб-интерфейсом для управления.
* **Контейнеры:** `mysql` (сервер БД) + `phpmyadmin` (веб-панель для администрирования таблиц, пользователей и выполнения SQL-запросов).

### 4. PostgreSQL
Мощная объектно-реляционная база данных с открытым исходным кодом, известная своей надёжностью и поддержкой сложных стандартов SQL.
* **Контейнеры:** Одиночный сервис `postgres` с настроенными томами (Volumes) для сохранения данных.

### 5. PostgreSQL + pgAdmin
Стек из базы данных PostgreSQL и самого популярного графического инструмента для её администрирования.
* **Контейнеры:** `postgres` + `dpage/pgadmin4` (веб-интерфейс для мониторинга и управления БД).

### 6. drawDB
Современный и удобный open-source инструмент для визуального проектирования схем баз данных (диаграмм сущность-связь / ERD) прямо в браузере.
* **Контейнеры:** Контейнеризированная версия веб-приложения drawDB для локального использования без ограничений.

### 7. LibreDB Studio
Универсальная свободная веб-студия или легковесный интерфейс для работы с базами данных (часто используется как альтернатива коммерческим аналогам для работы с Libre-стеком).
* **Контейнеры:** Готовый к работе образ LibreDB Studio с пробросом портов.

### 8. Homehub
Специализированное решение или панель (Dashboard) для систем умного дома или организации домашнего сервера (Self-hosted инфраструктуры).
* **Контейнеры:** Приложение Homehub, настроенное на хранение конфигураций в локальных папках хоста.

### 9. CloudBeaver
Облачный универсальный менеджер баз данных от компании DBeaver. Поддерживает работу с PostgreSQL, MySQL, Oracle, SQLite и другими БД через красивый веб-интерфейс.
* **Контейнеры:** Сервер CloudBeaver, предоставляющий доступ к управлению любыми удалёнными или локальными базами данных через браузер.

## 🛠️ Как использовать эти проекты

1. Установите **Docker** и **Docker Compose** на ваш компьютер или сервер.
2. Перейдите в директорию интересующего вас проекта.
3. Скопируйте файл `docker-compose.yml` (и при необходимости `.env` файл с переменными окружения).
4. Запустите стек командой:
   ```bash
   docker compose up -d
   ```
5. Для остановки сервисов с сохранением данных выполните:
   ```bash
   docker compose down
   ```
